wiki-mcp

This server exposes a markdown second brain (Obsidian vault) over the Model Context Protocol. Tools: wiki_search, wiki_get, wiki_related, wiki_recent, wiki_handover, wiki_stats, wiki_append, wiki_create.

Endpoint: /mcp (streamable HTTP). Everything except this page and /health requires a Bearer token.

claude mcp add --transport http wiki https://YOUR-DOMAIN/mcp \
  --header "Authorization: Bearer <token>"
