What you get

      
Everything a second brain needs, none of the lock-in.

      
Plain markdown with YAML frontmatter and [[wikilinks]]. Git is the database. Claude Code is the librarian.

    

    

      
Typed entities
People, clients, projects, tools, concepts, places, recipes — each one file, each with a one-sentence description that drives recall, sources, confidence and freshness.

      
MCP on every device
One Python file exposes search, outline, get, related, recent, append and create. Run it over stdio locally or behind a token on Docker for the Claude app, claude.ai and other agents.

      
Search that is measured
BM25, weighted term-match and a local embedding lane fused with reciprocal rank fusion. A query set and retrieval-eval.py report recall@5 and MRR so ranking changes are safe.

      
Ingest that keeps receipts
Email, meeting transcripts and phone captures land in the vault with their source path. Contradictions are flagged, never overwritten. Nothing is deleted; merges leave redirects.

      
Freshness by design
Stale pages by type, undated prices and versions, missing provenance — one lint script lists them. Archived things stop nagging; active things get downweighted when they go quiet.

      
Routines that reflect
Cloud routines for ingest, pre-meeting briefs, weekly digest, lint and a Sunday “reflect” pass that rewrites summaries and proposes merges — proposals only, you decide.

MCP tools

      
Work in layers: search, outline, then only the section you need.

      
Compact hits first (about 60 tokens each), then the outline, then one section. Read-only tools are annotated as such; write tools commit and push.

    

    

      
ToolWhat it does

      
wiki_searchQuery across entity, aliases, description, tags and body. Three lanes (BM25 · weighted match · embeddings) fused with RRF; stale pages weigh less; redirects hidden. Returns slug, type, description, path, score, snippet.

      
wiki_outlineFrontmatter head plus every ## section with its first line and length. Cheap way to decide what to read.

      
wiki_getA whole page, or just one section with section=. Cite as path#heading.

      
wiki_relatedOutbound and inbound links, dead links, and semantic neighbours.

      
wiki_recentPages changed in the last N days by last_updated.

      
wiki_handoverThe latest task handover, so a new session continues where the last one stopped.

      
wiki_statsPages per type, dirty files, last commits.

      
wiki_appendAdd knowledge to a page with section and source. Deterministic contradiction check on email, phone, prices, versions, contact person and hosting → callout + review queue.

      
wiki_createNew page following the schema. Refuses duplicates and anything that looks like a secret.

    

  






  

    

      
Docs · quick start

      
From clone to a working brain in ten minutes.

      
You need Claude Code, Python 3.10+ and Obsidian (optional but recommended). Everything else is in the repo.

    

    

      

        
1
Clone and name it
Run the setup interview inside Claude Code. It asks for your name, role and stack and creates the first entities.
git clone https://github.com/mahope/mimisbrunn.git my-brain
cd my-brain && claude
> /wiki-setup

        
2
Turn on the secret gate
A pre-commit hook blocks API keys, tokens and private keys before they reach git.
git config core.hooksPath .githooks

        
3
Serve it to Claude
Register the MCP server once; every Claude Code session can now search and write to the brain.
pip install "mcp>=1.12,<2" pyyaml fastembed
claude mcp add wiki -s user -- python /path/to/my-brain/scripts/wiki-mcp-server.py

        
4
Use it from your phone
Deploy deploy/wiki-mcp/ with Docker (Dokploy compose included), then add it as a custom connector in the Claude app with a Bearer token.
claude mcp add --transport http wiki-remote https://YOUR-DOMAIN/mcp \
  --header "Authorization: Bearer <token>"

Scripts

Hooks for Claude Code

          
wiki-context.py runs at session start and injects the critical facts plus the pages that match the project folder you opened. wiki-autocommit.py commits only the wiki file you changed and aborts a failed rebase instead of leaving the vault broken. See docs/automation-setup.md.

        

        
Capture from anywhere: forward a mail to your brain’s address, or message the optional Telegram bot (deploy/wiki-inbox/). A daily triage routine files it on the right page or parks it in the review queue — it never invents new pages.

      

    


    

      
Questions people ask

      
Does it need a vector database?
No. Search runs on SQLite FTS5 (BM25) plus an optional local embedding index built with fastembed. The markdown files remain the source of truth; the index is rebuilt from them and is git-ignored.

      
What happens when two sources disagree?
The new value goes into the text, the old one is preserved in a warning callout, and a line is added to _review-queue.md. Nothing is silently overwritten.

      
Can I run it without Claude?
The vault is plain markdown and the MCP server speaks the open Model Context Protocol, so any MCP client works. The skills and hooks are written for Claude Code.

      
Is anything sent anywhere?
Only what you configure. The template contains no keys, and the pre-commit hook blocks secrets. Embeddings are computed locally. Cloud routines are optional.
